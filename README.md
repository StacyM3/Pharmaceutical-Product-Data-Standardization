# Pharmaceutical Product Data Standardization

This project demonstrates how pharmaceutical product catalogs can be cleaned and standardized for use in supply chain systems, ecommerce platforms, and pharmaceutical databases.

## Objectives

- Standardize inconsistent medicine product names
- Match brand names to generic APIs
- Structure pharmaceutical catalog data
- Document AI-assisted catalog cleaning workflows

## Example Problem

Raw product names often appear as:

Panadol tab
PANADOL 500MG TABS
Panadol tablets 500

These must be standardized to:

Panadol 500 mg Tablets 10's

## Skills Demonstrated

Pharmaceutical catalog management  
Data cleaning  
Product classification  
AI-assisted workflows  
Healthcare ecommerce data standards
